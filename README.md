# JWStudy

6년차 퍼블리셔가 AI 바이브코딩으로 작은 화면을 만들며 자바스크립트와 React를 익히는 학습 프로젝트입니다.
강사 한 명과 학습자 한 명이 각자의 PC에서 이 저장소를 함께 씁니다.

세 가지로 이루어져 있습니다.

- **웹**: 길잡이와 커리큘럼을 보여 주고, 두 사람이 주고받은 기록을 보여 줍니다. Vite + React로 만들어져 있어 소스 자체가 예제입니다.
- **스킬**: Claude Code에서 쓰는 명령 세 개(`/study`, `/teach`, `/handoff`). 공부를 진행하고 기록을 씁니다.
- **기록**: `records/` 폴더의 JSON 파일. 스킬이 쓰고, git으로 주고받고, 웹이 읽습니다.

## 처음 한 번

Node.js 18 이상과 Claude Code가 필요합니다.

```
git clone <저장소 주소>
cd JWStudy
npm install
```

그다음 이 폴더에서 Claude Code를 열고 `/handoff 받기`를 실행합니다. 강사인지 학습자인지 한 번 묻고 `.jwstudy-role` 파일에 기억합니다. 이 파일은 PC마다 달라서 git에 올라가지 않습니다.

## 웹 실행

```
npm run dev
```

터미널에 표시되는 주소(기본 http://localhost:5173)를 브라우저에서 엽니다.

| 화면 | 주소 끝 | 내용 |
| --- | --- | --- |
| 길잡이 | `#guide` | 역할 주기, 일곱 단계, 프롬프트 모음, 확인 항목 |
| 이번 주 | `#week` | 주차별 과제와 그 주의 제출, 피드백, 질문, 프롬프트 기록 |
| 기록 | `#notes` | 개념 사전, 전체 질문함, 전체 프롬프트 기록 |
| 커리큘럼 | `#curriculum` | 강사용 12주 계획, 점검, 평가 기준 |

웹에는 입력 칸이 없습니다. 기록은 모두 스킬로 씁니다.

## 한 주의 흐름

| 누가 | 명령 | 하는 일 |
| --- | --- | --- |
| 학습자 | `/study` | 지난 피드백과 이번 주 과제를 듣고 공부를 진행 |
| 학습자 | `/handoff 질문` | 20분 넘게 막힌 것을 강사에게 |
| 학습자 | `/handoff 제출` | 과제를 마치고 내 말로 적어 제출 |
| 강사 | `/handoff 받기` | 새 제출과 질문 확인 |
| 강사 | `/teach` | 세션 준비: 결과물 요약, 물어볼 질문, 점검표, 시연 제안 |
| 둘 | (세션 60분) | 학습자가 설명하고 강사가 듣는다 |
| 강사 | `/handoff 피드백` | 잘한 것 하나, 다시 볼 것 하나, 통과 여부 |
| 학습자 | `/handoff 받기` | 피드백과 답변 확인 |

push는 스킬이 매번 확인을 받은 뒤에 합니다.

## 누가 어느 폴더를 쓰는가

| 경로 | 쓰는 사람 | 내용 |
| --- | --- | --- |
| `homework/` | 학습자 | 과제 코드. 주차마다 폴더 |
| `records/learner/` | 학습자 | 확인 항목, 개념 사전, 주차별 제출·프롬프트·질문 |
| `records/instructor/` | 강사 | 주차별 피드백·세션 기록·통과·답변 |
| `records/settings.json` | 강사 | 1주차 시작일 |
| `src/`, `.claude/` | 강사 | 웹 소스와 스킬 |

서로 남의 폴더는 읽기만 합니다. 같은 파일을 두 사람이 고치지 않으므로 git 충돌이 나지 않습니다.
기록 파일의 모양은 `.claude/skills/handoff/records-format.md`에 있습니다.

## 소스 구조

| 경로 | 역할 |
| --- | --- |
| `index.html` | 화면이 그려질 빈 자리(`#root`)와 글꼴 링크 |
| `src/main.jsx` | `App` 을 `#root` 에 그리는 시작점 |
| `src/App.jsx` | 위쪽 메뉴와 화면 전환 |
| `src/pages/` | 화면 네 개: `Guide`, `ThisWeek`, `Notes`, `Curriculum` |
| `src/components/` | 프롬프트 상자, 단계 카드, 질문 목록 같은 화면 조각 |
| `src/data/guide.js` | 길잡이의 글 내용 |
| `src/data/curriculum.js` | 커리큘럼의 글 내용. 주차·점검·평가 기준 |
| `src/data/commands.js`, `src/data/notes.js` | 명령 안내, 개념 사전의 용어 목록 |
| `src/store/records.js` | `records/` 파일을 읽어 화면에 넘기는 곳 |
| `src/lib/weeks.js` | 시작일로 주차와 날짜 범위 계산 |
| `src/styles.css` | 전체 스타일. 색과 글꼴은 맨 위 `:root` 변수 |
| `.claude/skills/` | 스킬 세 개 |

글 안에서 `` `백틱` `` 으로 감싼 부분은 코드 모양으로 표시됩니다.

## 한 파일로 만들기

```
npm run build:single
```

프로젝트 폴더에 `jwstudy.html` 이 만들어집니다. 만든 시점의 기록까지 들어 있는 한 파일이라, 서버 없이 더블클릭으로 열 수 있습니다.

## 학습자 과제로 남겨 둔 것

웹의 다음 기능은 일부러 만들지 않았습니다. 커리큘럼의 해당 주에 학습자가 직접 붙입니다.

- 6주차: 길잡이의 프롬프트 모음에 검색과 필터
- 9주차: `#` 전환을 React Router로 바꾸기
- 10~11주차: 타입스크립트로 옮기기
